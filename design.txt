[신규 기능 개발 지시서: 지역별 복권 분석 통계 3종 세트 구현]

현재 앱의 '지역별 통계' 화면을 단순 목록 이동용이 아닌, 유저들에게 유용한 분석 데이터를 제공하는 페이지로 확장하고자 합니다.
아래 3가지 통계 기능을 DB/백엔드 query 및 프론트엔드 UI까지 완벽히 구현해 주세요.

---

### 1. 지역별 '명당 밀도(행운 지수)' 계산 기능
- **개념**: 단순 당첨 횟수가 아닌 `(해당 지역의 총 1등 당첨 횟수) ÷ (해당 지역의 운영 중인 총 판매점 수)`를 계산하여 매장 1개당 평균 1등 당첨 비율(행운 지수)을 산출합니다.
- **백엔드/DB**:
  - `stores` 테이블(지역별 전체 판매점 수)과 `winning_history` 또는 `lotto_stores` 테이블(1등 당첨 이력)을 GROUP BY (시/도)하여 행운 지수 스코어를 계산하는 Supabase RPC 함수 또는 API엔드포인트를 작성하세요.
- **UI/UX**:
  - 카드 형태 리스트로 표시하며, 지표가 높은 순(내림차순)으로 정렬합니다.
  - 예시 표기: "강원 특별자치도 - 매장당 평균 1등 0.42회 (전국 명당 밀도 1위 🏆)"

---

### 2. '최근 핫스팟' 트렌드 모니터링 (최근 기운)
- **개념**: 누적 데이터가 아닌, 최근 회차(예: 최근 4주, 최근 10주) 기준 가장 당첨 기운이 좋은 지역을 추출합니다.
- **기능 요구사항**:
  - 상단 필터: `[최근 4주]` / `[최근 10주]` / `[전체 누적]` 탭 전환 기능 제공
  - 배지/하이라이트 표시:
    - 🔴 **이번 달 HOT 지역**: 최근 4주간 1등 배출 수가 가장 많은 시/도
    - ⚡ **연속 당첨 지역**: 최근 3주 이상 연속으로 1등이 배출된 시/군/구 추출
- **UI/UX**: 통계 페이지 최상단에 슬라이드 카드(Carousel) 또는 강조 하이라이트 박스로 배치하세요.

---

### 3. '자동 vs 수동' 지역별 성향 분석
- **개념**: 지역(시/도)별 1등 당첨 건 중 '자동 / 수동 / 반자동'의 비율(%)을 시각화합니다.
- **데이터 로직**:
  - DB의 당첨 데이터 중 `type` (자동/수동/반자동) 컬럼을 그룹화하여 지역별 비율 계산.
- **UI/UX**:
  - 각 지역 카드를 클릭하거나 펼쳤을 때, 가로 프로그레스 바(Progress Bar)나 도넛 차트 형태로 시각화해 주세요.
  - 예시: `서울 (자동 75% | 수동 20% | 반자동 5%)`

---

### 공통 처리 지시사항
1. 가짜(Mock) 데이터가 아닌, 실제 DB의 데이터를 기반으로 정확히 계산되도록 Supabase Query / API 로직을 작성하세요.
2. 데이터 로딩 중에는 Skeleton UI를 적용하여 자연스러운 UX를 제공하세요.
3. 계산 결과 화면에서 특정 지역 카드를 터치하면, 기존처럼 해당 지역이 필터링된 [명당 랭킹] 화면으로 파라미터(`sidoName`)를 넘기며 이동해야합니다.

[UI/UX 개선 지시서: '최근 회차'와 '최근 회차 목록' 영역 통합]

현재 지역 통계 화면에 '최근 회차' 영역과 '최근 회차 목록' 영역이 서로 분리되어 있어 화면이 산만합니다.
이 두 영역을 하나의 '최근 회차 당첨 현황' 컴포넌트로 통합해 주세요.

1. 통합 컴포넌트 구조:
   - [상단 요약 영역]: 
     - 가장 최근 회차 정보 (예: 제 1120회 당첨 현황)
     - 해당 회차의 총 당첨자 수 및 자동/수동/반자동 비율 요약
     - 이번 회차에 1등이 배출된 주요 지역 하이라이트
   - [하단 상세보기 버튼 및 아코디언(Accordion)/확장 리스트]:
     - "이번 회차 당첨 판매점 전체보기 (N곳)" 버튼 배치
     - 버튼 클릭 시 해당 회차에서 1등/2등을 배출한 전국 판매점 상세 목록이 아코디언 형태로 아래로 펼쳐지도록 구현

2. UX 요구사항:
   - 기본적으로는 요약 정보만 깔끔하게 보이고, 상세 목록은 유저가 원할 때만 펼쳐볼 수 있도록 접어두는(Collapsible) 방식을 적용하세요.
   - 목록 내 판매점 클릭 시 기존처럼 해당 판매점 지도/상세 페이지로 이동하는 로직을 유지하세요.
