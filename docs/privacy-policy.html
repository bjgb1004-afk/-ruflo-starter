개인정보처리방침

복권명당 (로또 명당 추천 서비스)
최종 수정일: 2026년 8월 9일

1. 개요

복권명당("앱")은 사용자의 위치 정보를 기반으로 주변 로또 판매점을 추천하고 명당 정보를 제공하는 서비스입니다. 본 개인정보처리방침은 앱이 수집, 사용, 관리하는 개인정보에 관한 정책을 명시합니다.

2. 수집하는 개인정보

필수 수집 정보:

  • 위치 정보 - 사용자의 GPS 위치 (위도, 경도)
  • 기기 정보 - 기기 고유 식별자, OS 버전, 앱 버전
  • 사용 통계 - 앱 사용 시간, 검색 기록, 클릭 데이터

선택 수집 정보:

  • 즐겨찾기 (사용자가 저장한 판매점 목록)
  • 알림 설정 (위치 기반 알림 허용 여부)
⚠️ 주의: 위치 권한 없이는 서비스 이용이 불가능합니다. 앱 첫 실행 시 위치 권한을 요청하며, 거부할 경우 앱 사용이 제한됩니다.

3. 정보 수집 방식

  • 능동적 수집: 사용자가 앱을 실행할 때 위치 권한 요청
  • 자동 수집: 지도 조회, 검색 기록, 앱 클릭 이벤트
  • 서드파티: Google Maps (위치 표시), Supabase (데이터 저장)

4. 정보 사용 목적

  • 사용자 위치 기반 주변 로또 판매점 추천
  • 명당 정보 제공 및 순위 표시
  • 위치 기반 알림 서비스
  • 앱 서비스 개선 및 사용자 분석
  • 오류 모니터링 및 성능 개선

5. 정보 저장 및 보관

  • 위치 정보: 실시간 처리만 하며, 서버에 저장하지 않습니다 (단, 알림 설정 시 필요한 좌표만 저장)
  • 즐겨찾기: 사용자 단말기의 로컬 저장소에 저장
  • 사용 통계: PostHog 분석 플랫폼에 30일간 저장 후 삭제
  • 오류 로그: Sentry 서비스에 저장, 최대 90일 보관

6. 제3자 정보 공유

사용자 개인정보는 다음과 같은 서드파티 서비스와 공유됩니다:

  • Google Maps: 위치 표시 및 지도 렌더링
  • Supabase: 판매점 정보 및 알림 설정 저장
  • PostHog: 앱 사용 분석 및 통계
  • Sentry: 오류 모니터링 및 성능 추적

공유하지 않는 정보: 개인 신원, 연락처, 결제 정보 등은 수집하지 않으며 제3자와 공유하지 않습니다.

7. 개인정보 보호

  • 모든 통신은 HTTPS를 통해 암호화됩니다
  • API 키는 환경 변수로 관리되며, 소스 코드에 노출되지 않습니다
  • 사용자 데이터는 접근 권한이 제한된 Supabase에만 저장됩니다
  • 정기적인 보안 업데이트로 취약점을 점검합니다

8. 사용자 권리

사용자는 다음의 권리를 행사할 수 있습니다:

  • 접근권: 본인 정보 조회 요청
  • 수정권: 부정확한 정보 수정 요청
  • 삭제권: 개인정보 삭제 요청
  • 거부권: 권한 설정을 통해 위치 공유 거부 가능

권리 행사는 앱 내 설정 메뉴의 "지원" 또는 이메일로 요청할 수 있습니다.

9. 개인정보 보유 기간

  • 위치 정보: 실시간만 사용, 서버 저장 안 함
  • 즐겨찾기: 사용자가 삭제할 때까지 보유
  • 사용 통계: 30일 후 자동 삭제
  • 오류 로그: 90일 후 자동 삭제

사용자가 앱을 제거하면 관련 개인정보는 즉시 삭제됩니다.

10. 아동 개인정보

본 앱은 만 14세 미만의 아동을 대상으로 하지 않습니다. 부모/보호자의 동의 없이 아동의 정보를 수집하지 않습니다.

11. 정책 변경

본 개인정보처리방침은 법률 변경 또는 서비스 개선으로 인해 사전 고지 없이 변경될 수 있습니다. 변경 시 앱 내 공지 또는 이메일 알림을 드립니다.
