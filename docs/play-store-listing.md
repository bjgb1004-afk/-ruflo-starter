# 구글 플레이 스토어 등록 텍스트 초안

콘솔(play.google.com/console) → 스토어 등록정보에 그대로 붙여넣으면 됩니다.

## 짧은 설명 (80자 이내)
```
로또 명당을 지도에서 찾고 1·2등 이력·랭킹 확인, 당첨번호 조회부터 QR 당첨확인, 즐겨찾기까지 한번에
```
(영문 환산 약 56자 — 여유 있음)

## 전체 설명 (4000자 이내)
```
📍 내 주변 로또 명당, 지도에서 바로 찾으세요

복권명당은 전국 로또(동행복권) 판매점의 1등·2등 당첨 이력을 기반으로
"명당" 판매점을 찾아주는 위치 기반 정보 서비스입니다.

■ 주요 기능

🗺️ 내 주변 판매점 지도
현재 위치 기준으로 가까운 로또 판매점을 지도에서 바로 확인하세요.
추천순, 거리순으로 정렬해서 볼 수 있고, 최신 회차 1등 배출 소식도
지도 상단에서 바로 확인할 수 있습니다.

🏪 판매점 상세정보
전화번호, 길찾기, 영업시간은 물론 화장실·ATM·편의점·카페 등
주변 편의시설 정보까지 한 화면에서 확인하세요.

🏆 전국·시도별 명당 랭킹
전국 및 시도별 TOP100 랭킹을 제공합니다. 판매점별 전국/시도/시군구
순위와 1등·2등 배출 횟수, 1년·5년 내 1등 배출 이력, 최근 당첨 이력까지
상세하게 확인할 수 있습니다.

🎯 QR 스캔 당첨 확인
보유한 로또 용지를 QR코드로 스캔하면 당첨 여부를 즉시 자동으로
확인해드립니다. 스캔한 용지는 회차별로 "내 복권 보관함"에 저장되어
언제든 다시 확인할 수 있습니다.

🔢 회차별 당첨번호 조회
최신 회차 당첨번호와 1~5등 당첨금(세후 예상 금액 포함)을 한눈에
확인하고, 1등 배출 지역과 당첨 판매점 목록도 함께 볼 수 있습니다.

⭐ 즐겨찾기
자주 가는 판매점을 즐겨찾기에 등록해두고 빠르게 다시 찾아보세요.

■ 이런 분들께 추천합니다
- 매주 로또를 구매하지만 어디서 사야 할지 고민되시는 분
- 우리 동네에서 당첨 이력이 많은 판매점이 궁금하신 분
- 로또 용지를 일일이 대조하지 않고 빠르게 당첨 확인하고 싶으신 분

■ 안내사항
본 앱은 로또 판매점 위치 정보 제공 서비스이며, 복권 구매·판매를
직접 중개하지 않습니다. 모든 데이터는 공개된 공공데이터 및
동행복권 공식 발표 정보를 기반으로 하며, 향후 당첨 확률을
보장하지 않습니다. 실제 구매는 반드시 정식 판매점을 이용해주세요.
```

## 카테고리
- 추천: **도구(Tools)** 또는 **지도/내비게이션(Maps & Navigation)**
- 비추천: "카지노"/"도박" 카테고리 — 이 앱은 정보성 서비스이므로 해당 카테고리 선택 시 오히려 부적절한 심사를 받을 수 있음

## 콘텐츠 등급 설문 가이드
Play Console 콘텐츠 등급 설문에서:
- "도박 관련 콘텐츠가 있습니까?" → **아니오** 선택 근거: 앱 내에서 베팅, 결제, 복권 구매를 일체 수행하지 않음. 이미 추첨된 공개 당첨 결과와 판매점 위치 정보만 제공.
- "실제 화폐로 도박할 수 있는 기능이 있습니까?" → **아니오**
- 위치 정보 수집 여부 → **예** (백그라운드 위치 포함, 명당 알림 기능 근거로 명시)

## 데이터 보안(Data Safety) 폼 답변 가이드
`docs/privacy-policy.html` 내용 기준:

| 데이터 유형 | 수집 여부 | 용도 | 공유 여부 |
|---|---|---|---|
| 위치(대략/정확) | 예 | 앱 기능(주변 판매점 검색, 명당 알림) | 공유 안 함 (Google Maps 렌더링에만 전달) |
| 앱 활동(검색기록, 클릭) | 예 | 분석 | PostHog와 공유 |
| 기기 ID | 예 | 분석/충돌 진단 | PostHog, Sentry와 공유 |
| 이메일 | 선택 (회원가입 시) | 계정 관리 | Supabase에만 저장, 외부 공유 안 함 |

- "데이터가 암호화되어 전송됩니까?" → **예** (HTTPS)
- "사용자가 데이터 삭제를 요청할 수 있습니까?" → **예** (이메일 요청 또는 앱 삭제 시 로컬 데이터 즉시 삭제)

## 백그라운드 위치 권한 선언 (Play Console 별도 양식)
"이 앱이 백그라운드 위치를 사용하는 이유"에 아래 문구 사용:
```
사용자가 사전에 선택한 로또 명당 판매점 근처에 진입했을 때 알림을 보내는
"명당 알림" 기능의 핵심 기능입니다. 앱이 꺼져 있거나 백그라운드 상태일 때도
근접 알림을 받기 위해 백그라운드 위치 권한이 반드시 필요하며, 이 기능은
설정 화면에서 사용자가 언제든 켜고 끌 수 있습니다.
```
